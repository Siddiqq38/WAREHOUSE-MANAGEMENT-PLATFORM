# W.M.P — Warehouse Management Platform

Platform pengelolaan gudang terpusat untuk DC 38 Tigalapan: **People**, **WMS**, **WOS**, dan lapisan **Integrasi & Dokumen**.

W.M.P berfungsi sebagai **pusat pencatatan dan aktivitas gudang**, bukan sekadar portal: seluruh transaksi inbound/outbound, relokasi, cycle count, dan kegiatan gudang (WMS), serta pemberian task per operator dan eksekusinya (WOS, terhubung ke People/Employee), tercatat di sini.
